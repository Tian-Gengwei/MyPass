# 🔐 Vault 架构与核心业务

<架构最高红线>
- 库是一个目录，绝不是单文件！彻底抛弃 KeePass 单文件 KDBX 模型。
- 一条目一文件：`objects/` 目录下，类似 Git 的 Hash 切片存储（如 `a1/b2/a1b2...enc`）。
- 一附件一文件：`attachments/` 目录下独立存储。
- 局部更新：修改条目仅重写对应的几 KB `.enc` 文件，杜绝全库重写。
- 单向兼容：仅支持 KDBX/Bitwarden/CSV -> Vault 导入，**绝对禁止**实现导出为 KDBX 的功能！
  </架构最高红线>
